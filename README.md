# Myths and Monsters Port

Unofficial Minecraft 1.12.2 (Cleanroom) port of **Myths and Monsters Mod** by HoopAWolf.

- Original: https://www.9minecraft.net/?p=12333
- Requires [ArchaicLib](https://www.curseforge.com/minecraft/mc-mods/archaiclib) 1.35.0+

This port contains **no original assets**. Put your own copy of the original jar (`modid_1.7.10_1.0.0.jar`) into `.minecraft/archaic_originals/`; ArchaicLib reads textures/sounds from it at runtime.
